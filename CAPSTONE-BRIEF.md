# ZAINAB AI — General AI Fluency Capstone

## Project Title

ZAINAB AI — AI-Powered Professional Portfolio & Personal AI Agent

## Purpose

ZAINAB AI is my General AI Fluency capstone project. It is an
AI-powered professional portfolio designed to present my learning
journey, Artificial Intelligence and Machine Learning work, AI
toolkit, and practical experience through an interactive website.

The project also includes ZIA (Zainab's Intelligent Assistant), a
personal AI agent that allows visitors to ask questions about my
education, projects, Machine Learning work, AI Fluency assignments,
skills, and learning journey.

## Problem

A traditional portfolio mainly presents static information. I wanted
to build a portfolio that could communicate my work while also
allowing visitors to interact with the information through an
AI-powered assistant.

The goal was to combine personal branding, AI collaboration,
software development, and responsible use of AI into one practical
project.

## ZIA — Personal AI Agent

ZIA stands for Zainab's Intelligent Assistant.

ZIA uses a structured knowledge base containing information about my
education, AI Fluency work, Machine Learning internship, projects,
skills, AI tools, and capstone.

The assistant also uses conversation history so that follow-up
questions can be understood in context.

Example questions include:

- What is Zainab studying?
- Tell me about her ML internship.
- What did she learn from FL-05?
- What was the result?
- What AI tools does she use?

## Machine Learning Work

The portfolio presents my Machine Learning Engineering internship
work with FlyRank AI.

The main Machine Learning problem was Content Refresh Opportunity
Scoring.

The goal was to rank webpages according to their potential
content-refresh opportunity.

The work included:

- Dataset exploration
- Feature preparation
- Baseline development
- Logistic Regression
- Decision Tree
- Random Forest
- Model evaluation
- Precision@50 analysis
- ML task framing
- Search Intelligence Data Contract
- Baseline action scoring

The dataset contained 30,000 rows and 44 columns.

The baseline achieved approximately 0.240 Precision@50, while the
Random Forest achieved approximately 0.740 Precision@50 in the
starter experiment.

## Responsible AI and Security

ZIA is designed to answer questions using information provided in its
portfolio knowledge base.

The system instructs the AI not to invent facts about Zainab.

The Gemini API key is stored in an environment variable rather than
being placed in frontend JavaScript.

The `.env` file is excluded through `.gitignore` and is not tracked
by Git.
